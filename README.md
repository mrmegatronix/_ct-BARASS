# Bar Assistant (`_ct-BARASS`)

Full client-side recreation of [Bar Assistant](https://github.com/karlomikus/bar-assistant) powered by the official [bar-assistant/data](https://github.com/bar-assistant/data) dataset (663 cocktails, 296 ingredients, glassware, methods, utensils, and real media).
